# Java Backend Engineering Notes

Practical engineering notes, examples, and architecture patterns for building production-grade Java and Spring Boot systems.

This repository is a growing companion to my LinkedIn engineering posts. Each topic is designed to move beyond theory and include implementation notes, trade-offs, code examples, diagrams, or performance considerations.

## About Me

I'm Shahrad Abghari, a Senior Java Backend Engineer / Technical Lead with extensive experience building backend and fintech platforms using Java, Spring Boot, microservices, REST APIs, messaging, caching, and distributed-system patterns.

My focus areas include:

- Java 21 and modern Java
- Spring Boot and Spring ecosystem
- Microservices and distributed systems
- High-throughput backend architecture
- API design and security
- Redis and caching strategies
- Kafka and asynchronous processing
- Database and JVM performance tuning
- Resilience patterns
- Observability
- Docker and Kubernetes

I have worked on large-scale backend platforms where production throughput reached thousands of transactions per second, with performance and stress testing around the 5K TPS range.

## Repository Philosophy

The examples in this repository are intentionally practical. The goal is not to demonstrate every framework feature, but to explain why a design is chosen, where it works well, where it fails, and what changes when traffic and operational complexity increase.

## Disclaimer

All examples are generic and educational. They do not contain proprietary source code, confidential architecture, customer data, or employer-specific implementation details.
